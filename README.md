# Prácticas de programación en Java

Colección formativa de ejercicios en **Java**, con ejemplos de consola, lógica, traducción sencilla y gestión de errores mediante excepciones.

## Organización

- `Practicar_casa/Practicar_en_casa/src/Ejercicios/`: ejercicios de Java y pruebas; incluye un minitraductor de palabras a inglés, italiano y alemán con validación de palabra e idioma.
- `Practicas_java/`: prácticas de consola, excepciones personalizadas y ejercicios adicionales.

El repositorio conserva carpetas de proyectos Java/Eclipse. Para trabajar sobre una actividad, abre el archivo `.java` correspondiente o importa el proyecto en Eclipse. Los archivos `.class` presentes son resultados compilados incluidos en el repositorio; el código fuente editable está en los directorios `src/` o junto a cada práctica.

## Requisitos

JDK instalado. Los ejercicios son independientes y pueden tener puntos de entrada distintos; compila y ejecuta cada clase desde la carpeta del ejercicio, respetando su `package` cuando corresponda.

## Temas de práctica

Fundamentos de Java, entrada por consola, condicionales, métodos y excepciones. Material de aprendizaje en desarrollo.
